Unde declar bean-urile vs. Unde le folosesc (Ex 1–5)

Ex 1 — XML Config (ex1-xml-configuration)
Unde declarÎn application-context.xml (<bean id="..." class="..."/>) și test-clients.xml
Cum folosescautowire="byType" în XML + <property ref="..."/> + context.getBean(...)
Ex 2 — Adnotări (ex2-annotation-dependencies)
Unde declarTot în application-context.xml (+ <context:annotation-config />)
Cum folosesc@Autowired pe câmpul repository în BankingImpl & BankReportServiceImpl
Ex 3 — Java Config (ex3-java-configuration)
Unde declar@Service pe clase (MapClientRepository, BankingImpl, BankReportServiceImpl) + @Bean în BankApplication
Cum folosesc@Configuration + @ComponentScan("com.luxoft.bankapp") + AnnotationConfigApplicationContext
Ex 4 — Spring Boot (ex4-spring-boot)
Unde declar@SpringBootApplication + @Service (+ @Profile("dev") pe DemoBankInitializationService)
Cum folosesc@Autowired, @Value("${feed.filename}") din application.yml, @PostConstruct
Ex 5 — AOP & Events (ex5-aop-events)
Unde declar@Service (BankingOperationsServiceImpl, AuditService), @Aspect @Configuration (AuditAspect), @Component (EventConditionFilter)
Cum folosesc@Pointcut / @Before / @Around → publishEvent(...) → @EventListener(condition = "...")

Tipuri de Autowiring & Tag-uri XML

autowire="byType"
Cum cautăDupă tipul parametrului din setter (ex: ClientRepository).
AtențiePică cu NoUniqueBeanDefinitionException dacă există 2+ bean-uri de același tip.
autowire="byName"
Cum cautăDupă numele proprietății/setter-ului (setRepository → caută id="repository").
AtențieÎn proiectul nostru id-ul e clientRepository, deci byName NU l-ar găsi!
autowire="constructor" vs "no"
constructorPotrivește argumentele constructorului după tip (similar cu byType).
no (default)Fără autowiring XML; legi manual cu <property ref="..."/> sau @Autowired (cazul Ex 2).

<constructor-arg> vs <property> și value vs ref

<constructor-arg>Apelează constructorul clasei la instanțiere: <constructor-arg name="name" value="${client1}" />
<property>Apelează setter-ul (setCity, setAccounts) după constructor.
value="..."Pasează valori simple: primitive, String, Enum, ${...}.
ref="..."Pasează referința către un alt bean din containerul Spring (ref="clientRepository").
